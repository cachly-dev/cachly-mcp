# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately here:

https://github.com/cachly-dev/cachly-mcp/security/advisories/new

This covers the MCP server in this repository (npm package `@cachly-dev/mcp-server`),
the API at `api.cachly.dev`, the endpoint `mcp.cachly.dev` and the website `cachly.dev`.

Please tell us what you did, what you saw, and which version you used. We confirm that we
received it, keep you posted while we work on a fix, and name you in the CHANGELOG if you
want that.

## Supported versions

Fixes go into the newest version on npm only. `npx @cachly-dev/mcp-server@latest` always
starts the newest one.
